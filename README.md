Web-Engine Chat - Discord-Style Reactions (v2)

This is a complete emoji reaction system designed for Chat and ChatBox modules, working both on websites and phpBB forums. It adds an interactive 😊 button to every message, which opens a panel with over 200 emojis organized into categories - smileys, gestures, hearts, animals, food, and objects. The selected reaction is displayed directly under the message as a styled badge with a counter and a list of the users who reacted. Clicking the badge again removes the reaction, and all changes are synchronized automatically every 5 seconds, with no need to reload the page.

The system recognizes both registered users and guests, supports light and dark themes, and integrates seamlessly into the existing chat interface through a MutationObserver that automatically adds buttons to newly arrived messages as well. The code is entirely Vanilla JavaScript, with no external dependencies, which makes it lightweight, fast, and compatible with any platform, including phpBB forums.
